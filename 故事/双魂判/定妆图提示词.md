# 《双魂判》定妆图提示词

## 构图规格

- **主定妆图：半身胸像（胸以上）**，竖屏 9:16。不要全身，不要纯脸部。
- 半身能同时锁住五官、发饰、服色、手持道具；全身会缩小面部导致后续视频锁不住脸。
- 主角（慎娘、锦姬、柳婉）可再补一张**脸部特写**作第二参考图，眼神与妆容更稳。
- 生成后：每个角色挑一张最满意的，后续镜头用它做首帧图生视频。

## 统一后缀（每条提示词末尾都加）

```
唐风古装，冷青灰调，柔和侧光，浅景深，半身构图（胸以上），素色背景，写实人像，电影质感，竖屏9:16，无卡通无动漫
```

## 负面提示词（可统一加）

```
卡通，动漫，3D渲染，夸张表情，现代元素， plastic skin，多余手指，畸形手，文字，水印
```

## 使用顺序

1. 先生成 1 号（慎娘主定妆）和 3 号（锦姬借身版），两张脸必须看起来是同一个人；如果不是，重生成 3 号，不要换 1 号。
2. 再生成 2 号（锦姬本体）、4 号（柳婉）、5 号（裴承业）。
3. 配角（6-9）最后生成，一致性要求低一些。
4. 定妆图定稿后，每镜提示词 = 对应角色的定妆图作为首帧 + 该镜的画面动作描述 + 统一风格后缀。

## 常见问题

### Q1：定妆图用即梦生成吗？
可以。即梦本身有图片生成功能，直接出定妆图最省事，而且和后续视频的风格同源，过渡更顺。
但即梦出图的人脸如果不稳定，可以换别的工具出图（见 Q3）。

### Q2：想要不一样的脸和身材，只能多试几次吗？
不用纯靠抽卡。**一次只改一个变量**，其他描述和统一后缀全部不动，这样才能看出是哪个词在起作用。

| 想改什么 | 替换的词（直接改提示词里对应部分） |
|---|---|
| 脸型 | 清瘦 → 鹅蛋脸／圆脸／方下颌／小巧瓜子脸 |
| 身材 | 清瘦 → 高挑纤长／娇小玲珑／丰腴 |
| 气质 | 眉眼沉静 → 目光锐利／眼波流转／怯生生 |
| 年龄 | 二十七八岁 → 三十许／二十出头 |
| 发型 | 低髻 → 高髻／半挽／垂发 |
| 服色 | 月白襦裙 → 藕荷／竹青／鸦青襦裙 |
| 肤色 | 肤色偏白 → 小麦色／冷白皮 |

**更稳的操作顺序**：
1. 先只生成「脸部特写」，专门挑一张满意的脸——脸单独抽比半身抽成功率高得多。
2. 脸定了，用这张图当参考图，再生成半身定妆图（服装、发簪、手势）。
3. 如果对某张图大体满意、只想微调，用**图生图/参考图重绘**，不要重新文生图从头抽——从头抽等于换了一张脸。
4. 如果工具支持固定随机种子（seed），锁住 seed 再改词，变量更可控。

### Q3：别的 AI 生成的图片，能拿给即梦当定妆图吗？
**可以，而且很常见。** 即梦支持上传参考图/首帧图，图片来源不影响使用。常见做法是：用出脸更稳的工具（如 Midjourney、Stable Diffusion）生成定妆图，再导入即梦做图生视频。

注意四点：
1. **风格必须统一**：导入的图也要写"写实人像、冷青灰调、电影感"，不要动漫/3D/油画风，否则转视频时容易崩脸。
2. **构图按规格来**：仍是竖屏 9:16、半身胸像、脸部清晰无遮挡。
3. **优先用即梦的"角色一致性/参考图"功能**（如果有），把定妆图作为角色参考上传，比只当首帧更稳。
4. **商用注意授权**：个人创作无所谓，若要发布变现，确认出图工具的商用条款。
