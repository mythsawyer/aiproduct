## 使用提示

1. **九宫格速查**：C1R1 = 001–027，C1R2 = 028–054，C1R3 = 055–081；C2R1 = 082–108，C2R2 = 109–135，C2R3 = 136–162；C3R1 = 163–189，C3R2 = 190–216，C3R3 = 217–243。每格内部固定按 M1→M2→M3、E1→E2→E3、T1→T2→T3 排列，所以「第几个」可以直接算出编号。
2. **换引擎等于换剧**：同一 C×R×M×T，只换 E（出走创业 / 团宠养成 / 取证揭穿）就是三条不同故事线，对应报告 6.5 节的结论。
3. **反转验收**：每条梗概的末尾都检查了相对位置是否真的改变；如果只是「知道了秘密」，应回到报告 6.6 节重写成身份、权力或关系的位移。
4. **与前 60 骨架表对照**：若要看某个组合在真实样本里的推荐度，用第二份文件 `女频爆款组合矩阵_五维笛卡尔积.md` 的 Top 60 骨架表按 C/M/E/T 查；本文件只负责「写出故事」，不负责「算热度」。
